# Modern 3D Interactive Portfolio

A stunning, modern portfolio website featuring 3D animations, interactive elements, and glass morphism design.

## ✨ Features

### 🎨 Modern Design
- **Glass Morphism UI**: Translucent cards with backdrop blur effects
- **Gradient Typography**: Beautiful gradient text effects
- **3D Hover Effects**: Interactive 3D transformations on hover
- **Modern Color Scheme**: Purple-blue gradient with accent colors

### 🚀 3D Interactive Elements
- **Particle Background**: Animated particle system (Three.js when available)
- **3D Cursor**: Custom cursor with magnetic effects
- **Smooth Animations**: GSAP-powered animations with fallbacks
- **Scroll Triggered Effects**: Elements animate as they come into view

### 📱 Responsive & Accessible
- **Mobile Optimized**: Touch-friendly interactions and responsive layout
- **Accessibility**: ARIA labels and keyboard navigation support
- **Performance**: Optimized loading with async scripts and fallbacks
- **Cross-browser**: Works across all modern browsers

### 🛠️ Technical Features
- **Progressive Enhancement**: Works without JavaScript, enhanced with it
- **Fallback Systems**: CSS-only animations when JS libraries aren't available
- **Modern CSS**: CSS Grid, Flexbox, Custom Properties
- **Optimized Assets**: Efficient loading and rendering

## 🎯 Sections

1. **Hero Section**: Animated introduction with typewriter effect
2. **About**: Experience timeline with animated counters
3. **Skills**: Interactive progress bars with skill percentages
4. **Services**: 3D service cards with hover effects
5. **Projects**: Filterable portfolio with 3D project cards
6. **Contact**: Modern contact form with glass morphism

## 🚀 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Animations**: GSAP (GreenSock) with fallbacks
- **3D Graphics**: Three.js (progressive enhancement)
- **Styling**: Modern CSS with custom properties
- **Icons**: Font Awesome
- **Responsive**: Bootstrap 5 grid system
